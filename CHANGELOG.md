# Changelog

Todos los cambios importantes realizados en el proyecto se documentan en este archivo.

## [1.0.0]

### Added

- Creación del proyecto SendMessage.
- Creación de SendActivity.
- Creación de ViewActivity.
- Diseño de interfaces mediante XML.
- Campo de texto para introducir mensajes.
- Botón para enviar mensajes.
- Comunicación entre Activities mediante Intent.
- Envío de datos mediante putExtra.
- Recepción y visualización del mensaje.
- Uso de recursos gráficos.
- Comprobación del ciclo de vida mediante Logcat.
- Depuración mediante breakpoints.
- Documentación mediante KDoc.
- Generación de documentación mediante Dokka.
